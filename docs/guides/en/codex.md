## Using with Codex

This AI gateway can also power Codex.

### Local desktop setup and mobile Remote Control

For the Windows Codex desktop app with a WSL backend, run `bun run setup:codex`
from the repository root after configuring the local gateway and its key file.
The installer updates the active device configuration, preserves other settings,
and installs the launch environment helper. Use `--cli` for the Linux/WSL CLI.
See [local setup](../../../deploy/local/README.md) for prerequisites, options,
backups, service status commands, and ChatGPT sign-in / QR pairing steps.

Recommended Codex version: `0.160.0` or newer. These clients can load the model catalog from `model_catalog_url`, so the local `model_catalog_json` file is optional.

Remote catalog responses are limited to 1 MiB of JSON. When the merged catalog is larger, the gateway keeps models selected through provider `agentsModels` first and drops the rest. Select the models you need on the Providers page, or generate a local catalog for the complete list.

When `modelMappings` maps a bare `model` to the same `codex/model`, the Codex catalog omits the duplicate `codex/model` entry and retains the bare entry's complete metadata. This also applies to the default `codex-auto-review` and `gpt-reserve` mappings. Explicit prefixed requests remain supported; mappings to another model or provider retain the prefixed entry.

### Codex `config.toml` Reference

Add this to `~/.codex/config.toml`:

```toml
model = "gpt-6.1-sol"
model_reasoning_effort = "max"
model_provider = "copilot_api"
model_reasoning_summary = "auto"
plan_mode_reasoning_effort = "max"
# Adjust the context window and auto-compaction threshold (in tokens) as needed.
# Under OpenAI API pricing, GPT models such as gpt-6.1-sol charge 2x input and
# cache rates and 1.5x output rates when input exceeds 272000 tokens.
model_context_window = 400000
# Sandbox policy. Use "workspace-write" to restrict it.
sandbox_mode = "danger-full-access"
approvals_reviewer = "auto_review"
suppress_unstable_features_warning = true
web_search = "live"
service_tier = "default"
# Optional: Codex 0.160.0+ loads the remote catalog above. Uncomment this only
# to use a local full catalog generated by docs/generate-model-catalog.sh.
# model_catalog_json = "model_catalog.json"

[model_providers.copilot_api]
name = "Copilot API"
base_url = "http://localhost:4141"
model_catalog_url = "http://localhost:4141/models"
requires_openai_auth = true
env_http_headers = { "x-api-key" = "GITHUB_COPILOT_API_KEY" }
supports_websockets = false
supports_standalone_web_search = true
wire_api = "responses"
request_max_retries = 3
stream_max_retries = 3
stream_idle_timeout_ms = 300000

[features]
remote_compaction_v2 = true
api_key_model_discovery = true
default_mode_request_user_input = true
standalone_web_search = true
daemon_auto_start = false
apps = false
prevent_idle_sleep = true
defer_mailbox_preemption = true
instant_interrupt = false

[desktop]
enabled-reasoning-efforts = ["low", "medium", "high", "xhigh", "ultra", "max"]

[analytics]
enabled = false
```

> [!NOTE]
> `name` is the provider display name. `"Copilot API"` was verified with the desktop WSL runtime `0.163.0-alpha.11`.
>
> **Mailbox Preemption:** Set `defer_mailbox_preemption = true` under `[features]` to defer sub-agent message preemption. By default, receiving a sub-agent message may cause the main agent to stop reading the SSE stream after a complete reasoning/commentary output item and start the next model request without waiting for `response.completed`.
>
> When enabled, receiving a sub-agent message no longer ends the current model response early. Messages are delivered at the next normal input-processing point, reducing brief overlaps where a new request starts before the previous one finishes. If you encounter `Encrypted function output content could not be decrypted or decoded` when using Codex with GitHub Copilot, try enabling this option.
>
> Sign in to Codex with ChatGPT when using mobile Remote Control. `requires_openai_auth = true` enables ChatGPT account authentication; `env_http_headers` supplies the gateway key separately through `x-api-key`. The gateway gives that header precedence over the ChatGPT `Authorization` header. Remove a provider `auth` command, `env_key`, or `experimental_bearer_token` when using this layout. Setting `requires_openai_auth = false` hides Remote in the desktop app ([openai/codex#36879](https://github.com/openai/codex/issues/36879)).
>
> Make `GITHUB_COPILOT_API_KEY` available to the process launching Codex and use one of the [gateway API keys](cli.md#auth-command-options). The local installer uses `COPILOT_API_GATEWAY_KEY` instead and reads it from a protected key file at launch. In WSL desktop mode the backend uses a Bash login shell, so a variable set only in `.zshrc` will not reach it.

### Auto Review Model Mapping

When using `approvals_reviewer = "auto_review"` through the top-level GitHub Copilot route, add this mapping to the gateway's `config.json`:

```json
{
  "modelMappings": {
    "codex-auto-review": "gpt-5.6-luna"
  }
}
```

Alternatively, set `"codex-auto-review": "codex/codex-auto-review"` to use the built-in `codex` provider.

### Generate `model_catalog.json`

Use a local catalog for the complete list, for Codex versions before `0.160.0`, or to avoid the 1 MiB remote response limit. The generator sends `x-full-model-catalog: true`, bypassing the size and default-exclusion limits while still respecting provider enable states and `agentsModels` selections. This header never reaches upstream providers. See [configuration](configuration.md) for provider selections.

Start the gateway, install `curl` and Bun or Node.js, then run [the generator](../../generate-model-catalog.sh) from the repository root:

```sh
sh docs/generate-model-catalog.sh
```

Defaults: gateway `http://localhost:4141`, output `$HOME/.codex/model_catalog.json`. To customize, append the gateway URL and output path in that order.

- **Authentication:** If enabled, export `GITHUB_COPILOT_API_KEY` before running the script.
- **Configuration:** After generation, uncomment `model_catalog_json` and set it to the file's absolute path.
- **Updates:** Rerun the script and restart Codex after changing gateway models or providers.

### Codex Model Catalog and Protocol Adapters

The catalog response adapts to the client version: Codex `0.160.0` and newer receive the canonical `model_messages.instructions_template` field without the deprecated `base_instructions` duplicate; older clients retain the legacy instruction fields.

### Codex Provider Price Estimates

Costs shown for the built-in `codex` provider are price estimates based on [OpenAI API pricing](https://developers.openai.com/api/docs/pricing), not actual Codex subscription charges or allowance consumption. The request's `service_tier` determines the uniform multiplier: `fast` / `priority` use 2×, and `ultrafast` uses 6×, without filtering by model. Other tiers use Standard prices. An upstream response reporting `default` does not override the requested tier.
